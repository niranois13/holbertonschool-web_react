# React Intro

React is a JavaScript library for building user interfaces, maintained by Meta (formerly Facebook) and a community of developers. It allows developers to create large web applications that can update and render efficiently in response to data changes.

## Features

- **Component-Based**: Build encapsulated components that manage their own state, then compose them to make complex UIs.
- **Declarative**: Design simple views for each state in your application, and React will efficiently update and render the right components when your data changes.
- **Learn Once, Write Anywhere**: React can be used for web, mobile (with React Native), desktop apps (with Electron), and more.

### Sample Component

```
function Welcome(props) {
  return <h1>Hello, {props.name}</h1>;
}
```
