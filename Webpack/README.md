# Webpack

![webpack](https://i.imgur.com/XwgYhk7.png)

This project uses **Webpack**, a powerful module bundler for modern JavaScript applications.

## What is Webpack?

Webpack takes modules with dependencies (JavaScript, CSS, images, etc.) and bundles them into optimized static assets for your project.
It helps you manage and transform all your front-end resources efficiently.

## Features

- Bundle JavaScript files
- Process CSS and images
- Development server with live reloading
- Support for modern JavaScript (ES6+)

## Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed:

```
node -v
npm -v
```

### Installation

1. Clone the repository:

```
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

2. Install dependencies:

```
npm install
```

### Available Scripts

- Runs Webpack Dev Server
- Opens your app in the browser
- Watches for changes and reloads automatically
